# 0001. Record lasting decisions in this folder

- **Status:** Accepted
- **Decided:** 2026-11-26

## Context

Several choices about evals, CI, releases, and naming were made in one
session and recorded only in commit messages. A contributor reading the code
sees what was done but not why, or what was rejected.

## Decision

Record each lasting decision as a short numbered page here, using
[the template](template.md). A record is never edited to change its
decision; a new record supersedes it.

## Consequences

Each record costs a few minutes. In return, a reversal starts from the
original reasons instead of from guesswork.
