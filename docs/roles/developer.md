# Developer

Build the change in steps a reviewer can follow, and review others' changes.

## Skills

| Skill | Reads | Produces |
| --- | --- | --- |
| [change-plan-author](../skills/change-plan-author.md) | A specification or request, and the code | Ordered, reviewable steps with files, checks, and sizes |
| [test-plan-author](../skills/test-plan-author.md) | The acceptance criteria | A test plan, and failing tests first when asked |
| [peer-code-review](../skills/peer-code-review.md) | A diff, commit, or pull request | A verdict and findings with file and line evidence |
| [documentation-author](../skills/documentation-author.md) | The change and its users | Pages that pass the bundled page check |

## What you approve

Each step's merge, after review.

## Where the skills connect

`change-plan-author` names the check for each step, and `test-plan-author` can write those tests before the code.
