# Operations

Ship releases safely, and keep the catalog and docs true.

## Skills

| Skill | Reads | Produces |
| --- | --- | --- |
| [release-notes-author](../skills/release-notes-author.md) | The changelog, the merged changes, and the code | Notes with upgrade steps, migrations, and how to roll back |
| [ci-workflow-review](../skills/ci-workflow-review.md) | CI workflow files | Findings and a verdict, without editing or running a workflow |
| [backstage-catalog-builder](../skills/backstage-catalog-builder.md) | Repositories and a running catalog | Registered entities, verified after ingestion |
| [documentation-review](../skills/documentation-review.md) | Documentation pages | Findings on accuracy, structure, and accessibility |

## What you approve

Each release, and each catalog registration.

## Where the skills connect

Release notes draw on the changelog that every skill change updates, and on decision records for the reasons behind breaking changes.
